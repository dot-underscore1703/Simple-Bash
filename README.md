# Simple-Bash
A version of Grey Hack's bash program stripped down to its minimum - 81.8% smaller than the official bash!

## Bash
This version of bash is not feature-rich and lacks the functionalities the official implementation has - such as the GetFinalPath function. That's right, I got rid of GetFinalPath. You have to type your commands in full - like '/bin/cd <path>' and '/bin/ls <path>'

It has no exit command, clear command or help command.
It does not give you the current working directory, its input prompt is simply '_sb> '



Why make such a thing?
Might confuse the unexperienced attacker.
Maybe you like making life hard for yourself.
Maybe you have big hacking scripts but not enough money for big hard disks?
